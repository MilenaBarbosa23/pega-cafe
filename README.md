# Pega Café ☕

## Objetivo
Jogo Web no estilo Infinite Runner onde o jogador precisa pular obstáculos (o cansaço) e coletar xícaras de café para manter a energia e sobreviver ao expediente. Uma paródia sobre a necessidade de cafeína.

## Tecnologias Utilizadas
- HTML5[cite: 1]
- CSS3[cite: 1]
- JavaScript (Puro)[cite: 1]

## Instalação e Execução
O jogo não requer instalação e roda diretamente no navegador[cite: 1]. 
Acesse a versão publicada no GitHub Pages através do link: **[COLE O LINK DO SEU GITHUB PAGES AQUI]**[cite: 1]

## Regras do Jogo
1. O jogo inicia ao clicar no botão "Iniciar Partida".[cite: 1]
2. Pressione a barra de espaço, a seta para cima ou clique na tela para pular.
3. Evite bater no obstáculo (💤) no chão.
4. Colete as xícaras de café (☕) no ar para somar pontos.[cite: 1]
5. A partida termina se você encostar no obstáculo (condição de derrota)[cite: 1]. Você pode reiniciar a partida para tentar uma pontuação maior.[cite: 1]
